# DEMIAND — пакет для GitHub Pages

Эта папка содержит только файлы, необходимые для работы сайта.

## Как загрузить

1. Создайте новый репозиторий на GitHub.
2. Откройте папку `DEMIAND_GitHub_Ready` и загрузите **всё её содержимое в корень репозитория**. Файл `index.html` должен находиться на верхнем уровне, а не внутри дополнительной папки.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. Через несколько минут GitHub покажет ссылку на опубликованный сайт.

Папки `tmp`, `sources`, `.agents` и `.codex` загружать не нужно.
