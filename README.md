# DEMIAND — сайт для международных дилеров

Это единственная актуальная рабочая версия сайта. Все следующие правки вносятся
в эту папку. Старые варианты и материалы проекта не нужны для запуска.

## Перенос в GitHub

1. Создайте репозиторий и перенесите **содержимое этой папки в его корень**.
2. Включите скрытые файлы: `.github/`, `.gitignore` и `.nojekyll` тоже нужны.
3. В GitHub откройте Settings → Pages → Source → GitHub Actions.
4. После загрузки в ветку `main` готовый процесс публикации проверит и разместит сайт.

Папки `dist` и `node_modules` переносить не нужно. Секреты и ключи доступа не требуются.
Сайт использует относительные пути и работает как на домене, так и в подпапке GitHub Pages.
Для ручной публикации без Actions можно выбрать ветку `main`, папку `/ (root)`.

## Локальный просмотр

Требуется Node.js 20 или новее. Установка библиотек не нужна.

```sh
npm run dev
```

Откройте http://127.0.0.1:4175/. Для 3D-модели используйте локальный сервер, а не `file://`.

```sh
npm run check
npm run build
```

Готовые файлы для любого статического хостинга появляются в `dist/`.

## Структура

```text
index.html
assets/
  css/      — стили, разделённые по ответственности
  js/       — взаимодействия и адаптация секций
  images/   — только изображения, используемые сайтом
  models/   — 3D-модель продукта
scripts/    — просмотр, проверка и сборка без зависимостей
.github/    — автоматическая публикация GitHub Pages
```

Тексты редактируются в `index.html`. Дизайн и поведение — в соответствующих файлах
`assets`. Не редактируйте `dist`: он создаётся заново при сборке.

## Важные ограничения

- Форма готовит письмо в почтовом приложении посетителя. Автоматической отправки
  или подключения к CRM нет. Адрес получателя: `partners@demiand.com`.
- Шрифты загружаются с Google Fonts, компонент 3D — с jsDelivr. Для них нужен интернет.
- Фирменные изображения и 3D-модель входят в папку; права на них остаются у владельца.
- Открытая публикация GitHub Pages делает файлы сайта доступными посетителям.


## Каталог

Данные моделей, артикулы и подписи swatches находятся в `assets/js/script.js`.
Каталог содержит 7 аэрогрилей, 3 кофемашины и 2 блендера. Размеры карточек
одинаковы во всех категориях и не зависят от количества моделей. По одной временной
фотографии используется для всех моделей соответствующей категории:

| Категория | Изображение | Модель на фото |
| --- | --- | --- |
| Air Fryers | `assets/images/catalog-airfryer-2700.png` | DK-2700 |
| Coffee Makers | `assets/images/catalog-coffee-3500.png` | KF-3500 |
| Blenders | `assets/images/catalog-blender-1200.png` | BL-1200 |

Исходные фотографии сохранены без ретуши и изменения пропорций. Изображение
занимает всю область контейнера с `object-fit: contain`; белая поверхность
и тонкая граница отделяют фото от фона секции. Swatches сохраняют активное
состояние, но пока не меняют фото. Их цвета иллюстративны и требуют подтверждения
перед подключением индивидуальных фотографий моделей и цветовых вариантов.

## Визуальная проверка

Контрольные desktop-размеры: 1366×768, 1440×900, 1600×900, 1920×1080.
Дополнительно проверяются 768×1024, 390×844 и 320×568. На desktop секции
укладываются в высоту окна; на телефонах длинные секции используют естественный
скролл. Каталог сохраняет горизонтальную ленту с кнопками, прокруткой и клавиатурой.

После изменения проверьте все категории, swatches, крайние положения ленты,
вкладки Market Potential, меню с клавиатуры и reduced motion. У TOP анимация
не использует обрезающую маску; Global Scalability сохраняет карту без маркеров.
`npm run build` проверяет также изображения, подключаемые через JavaScript.

## Производственное видео

В текущей версии остаётся визуальная заготовка производственного видео.
Для подключения реального материала замените `.production-video` внутри
`.production-film` на:

```html
<video controls playsinline preload="metadata" aria-label="DEMIAND production tour">
  <source src="assets/video/production.mp4" type="video/mp4" />
</video>
```

Создайте `assets/video` при добавлении видео и удалите `figcaption` этой заготовки,
чтобы подпись не закрывала нативные элементы управления.

Карта основана на общедоступных контурах Natural Earth (world-atlas 2.0.2).
Связи в отдельной секции International Network иллюстративны и не задают
подтверждённый список стран экспорта.
