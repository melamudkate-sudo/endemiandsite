# DEMIAND — сайт для международных дилеров

Это единственная актуальная рабочая версия сайта. Все следующие правки вносятся
в эту папку. Старые варианты и материалы проекта не нужны для запуска.

## Перенос в GitHub

1. Создайте репозиторий и перенесите **содержимое этой папки в его корень**.
2. Включите скрытые файлы: `.github/`, `.gitignore` и `.nojekyll` тоже нужны.
3. В GitHub откройте Settings → Pages → Source → GitHub Actions.
4. После загрузки в ветку `main` готовый процесс публикации проверит и разместит сайт.

Папки `dist` и `node_modules` переносить не нужно. Секреты и ключи доступа не требуются.
Сайт использует относительные пути и работает как на домене, так и в подпапке GitHub Pages.
Для ручной публикации без Actions можно выбрать ветку `main`, папку `/ (root)`.

## Локальный просмотр

Требуется Node.js 20 или новее. Установка библиотек не нужна.

```sh
npm run dev
```

Откройте http://127.0.0.1:4175/. Для 3D-модели используйте локальный сервер, а не `file://`.

```sh
npm run check
npm run build
```

Готовые файлы для любого статического хостинга появляются в `dist/`.

## Структура

```text
index.html
assets/
  css/      — стили, разделённые по ответственности
  js/       — взаимодействия и адаптация секций
  images/   — только изображения, используемые сайтом
  models/   — 3D-модель продукта
scripts/    — просмотр, проверка и сборка без зависимостей
.github/    — автоматическая публикация GitHub Pages
```

Тексты редактируются в `index.html`. Дизайн и поведение — в соответствующих файлах
`assets`. Не редактируйте `dist`: он создаётся заново при сборке.

## Важные ограничения

- Форма готовит письмо в почтовом приложении посетителя. Автоматической отправки
  или подключения к CRM нет. Адрес получателя: `partners@demiand.com`.
- Шрифты загружаются с Google Fonts, компонент 3D — с jsDelivr. Для них нужен интернет.
- Фирменные изображения и 3D-модель входят в папку; права на них остаются у владельца.
- Открытая публикация GitHub Pages делает файлы сайта доступными посетителям.
