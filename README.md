# DEMIAND — сайт для международных дилеров

Это единственная актуальная рабочая версия сайта. Все следующие правки вносятся
в эту папку. Старые варианты и материалы проекта не нужны для запуска.

## Перенос в GitHub

1. Создайте репозиторий и перенесите **содержимое этой папки в его корень**.
2. Включите скрытые файлы: `.github/`, `.gitignore` и `.nojekyll` тоже нужны.
3. В GitHub откройте Settings → Pages → Source → GitHub Actions.
4. После загрузки в ветку `main` готовый процесс публикации проверит и разместит сайт.

Папки `dist` и `node_modules` переносить не нужно. Секреты и ключи доступа не требуются.
Сайт использует относительные пути и работает как на домене, так и в подпапке GitHub Pages.
Для ручной публикации без Actions можно выбрать ветку `main`, папку `/ (root)`.

## Локальный просмотр

Требуется Node.js 20 или новее. Установка библиотек не нужна.

```sh
npm run dev
```

Откройте http://127.0.0.1:4175/. Для 3D-модели используйте локальный сервер, а не `file://`.

```sh
npm run check
npm run build
```

Готовые файлы для любого статического хостинга появляются в `dist/`.

## Структура

```text
index.html
assets/
  css/      — стили, разделённые по ответственности
  js/       — взаимодействия и адаптация секций
  images/   — только изображения, используемые сайтом
  models/   — 3D-модель продукта
scripts/    — просмотр, проверка и сборка без зависимостей
.github/    — автоматическая публикация GitHub Pages
```

Тексты редактируются в `index.html`. Дизайн и поведение — в соответствующих файлах
`assets`. Не редактируйте `dist`: он создаётся заново при сборке.

## Важные ограничения

- Форма готовит письмо в почтовом приложении посетителя. Автоматической отправки
  или подключения к CRM нет. Адрес получателя: `partners@demiand.com`.
- Шрифты загружаются с Google Fonts, компонент 3D — с jsDelivr. Для них нужен интернет.
- Фирменные изображения и 3D-модель входят в папку; права на них остаются у владельца.
- Открытая публикация GitHub Pages делает файлы сайта доступными посетителям.


## Визуальная версия для согласования

Изменения внесены непосредственно в эту папку. Секции на desktop не разбиваются
на дополнительные экраны; размер визуалов зависит от высоты окна. Основные
контрольные размеры: 1440×900 и 1920×1080.

### Замена визуальных заготовок

В `index.html` найдите комментарии `REPLACE WITH:`. Подготовлено 9 мест для изображений:

- Launch Kit: Brand Guidelines, Product / Marketplace Content,
  Social / Campaign Creative, Sales / Training Materials.
- Localization: Localization System — продукт, вилка, инструкция и упаковка.
- Quality: Incoming Inspection, Assembly, Functional Testing, Packaging.

Внутри соответствующего `.media-placeholder` замените элемент
`<span class="placeholder-label">…</span>` на `<img src="assets/images/your-image.jpg"
alt="Краткое описание на английском" loading="lazy" />`. Сохраните внешний контейнер,
подписи и атрибуты `data-preview` / `data-slot`: они нужны для переключения Launch Kit.
Четыре кнопки Launch Kit соответствуют четырём визуалам; первый выбран по умолчанию.

Для Manufacturing замените `.production-video` внутри `.production-film` на:

```html
<video controls playsinline preload="metadata" aria-label="DEMIAND production tour">
  <source src="assets/video/production.mp4" type="video/mp4" />
</video>
```

Создайте `assets/video` при добавлении видео. Исходный кадр может быть 16:9: широкий cinematic frame кадрирует его через object-fit: cover.
Удалите `figcaption` этой заготовки при подключении видео, чтобы подпись не закрывала
нативные элементы управления. До замены это визуальная заготовка, а не работающий плеер.

Карта использует статический SVG на основе общедоступных контуров Natural Earth
(world-atlas 2.0.2). Узлы и связи схематичны и не задают подтверждённый список стран экспорта.
Новых браузерных библиотек и зависимостей сборки не добавлено.


## Арт-директорская итерация · 8 сентября 2026

Обновлены стеклянная навигация, Commercial model, Manufacturing, Quality,
Launch Kit (4 кнопки / 4 визуала), Localization System, After-Sales, карта,
коммерческие якоря, Contact и иерархия metallic gold. Добавлены однократные

меню, клавиатура, все вкладки, аккордеон и подготовка письма без отправки.
Ошибок JavaScript, консоли и загрузки ресурсов при проверке не обнаружено.
`npm run build` проходит; проверка теперь также контролирует aria-связи и CSS assets.

Существующие 9 заготовок изображений и заготовка производственного видео
сохранены: для замены нужны реальные материалы. Инструкции приведены выше.


Навигация уточнена по визуальному референсу: жемчужное стекло, указатель More,
карточки 3×2 с разделителями и маленькими chevron; CTA без красной иконки.

Переходы секций используют только два значения `data-transition`:
`layered` — Advantages, SmartCook, Manufacturing и Contact; `wipe` — остальные.
Радиусы глав симметричны (32 px, Contact 44 px), overlap — 24 px.
Анимация фона предшествует контенту, не увеличивает scroll height и отключается
при reduced motion. При быстром переходе по якорю контент доступен сразу.


Последнее уточнение: шапка остаётся видимой во всех секциях. More компактнее,
имеет более контрастную жемчужную поверхность и плавное закрытие; hover меняет
тон круглого контрола без смещения chevron. High Market Position построен
на типографике TOP и двух показателях, без изображения продукта. Distribution
Ready — связанная схема с четырьмя пиктограммами. Commercial Potential —
компактная композиция с предложением слева и коммерческой цепочкой справа.
